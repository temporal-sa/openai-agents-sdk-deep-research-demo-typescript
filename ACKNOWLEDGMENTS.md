# Acknowledgments

This repository is a TypeScript rewrite of Temporal's
[OpenAI Agents SDK deep-research demo](https://github.com/temporal-sa/openai-agents-sdk-deep-research-demo).
The original Python project established the interactive research flow, agent
roles, and demonstration experience adapted here.

The implementation uses the
[OpenAI Agents SDK for TypeScript](https://openai.github.io/openai-agents-js/)
and the [Temporal TypeScript SDK](https://docs.temporal.io/develop/typescript).
